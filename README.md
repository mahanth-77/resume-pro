# Resume Pro

Premium ATS Resume Builder foundation.

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Current features
- Premium homepage
- Mock authentication + protected routes (Dashboard & Builder)
- Multi-step resume builder with **live preview**
- Clean single-column ATS-friendly preview
